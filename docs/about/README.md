# 关于本站

这是 Kaino·Lamperouge 的前端笔记站。日常做制造业相关的业务系统，前端技术栈以 Vue 为主，笔记大多来自实际项目里踩过的坑，而不是教程的复述。

## 这里有什么

- 样式与交互：动画、关键帧、透明度、背景图与常见视觉技巧；
- JavaScript：事件流、模块导出、对象与拷贝、Promise 与闭包；
- 图形渲染：Canvas 2D、WebGL 渲染管线、GLSL 着色器、Three.js 入门；
- 工程实践：npm / nvm / Shell、调试、性能优化、内存泄漏排查；
- uni-app：静态资源引用、CSS 变量、事件修饰符、组件通信；
- 小项目：计时器、批量删除等可以直接跑的练手 Demo。

## 技术栈

站点用 VuePress 2 + 默认主题构建，vite 打包，搜索基于 slimsearch 的全文索引，静态托管在 GitHub Pages。
